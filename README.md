# React Notes App

A simple notes app built with React and Tailwind CSS. You can add notes with a heading and details, and delete them when you don't need them. Notes are saved in the browser using localStorage, so they stay after a refresh.

Live demo: https://react-notes-app-cyan-mu.vercel.app/

## Features
- Add a note with a heading and details
- Delete a note
- Empty notes are not added
- Notes are saved in localStorage
- Responsive layout

## Tech Used
- React
- Tailwind CSS
- Vite
